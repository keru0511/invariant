# キャンセル規則の最小実証実験用コーパス

## 目的と現時点

同じ日本語ルールと事実を与えたとき、読取専用の決定論的プログラムへのアクセスが、LLMの境界判定、計算、欠測対応、会話中の規則維持にどう影響するかを比較するための架空の例です。

このコーパスと純粋関数のテストは実験の準備です。モデル試行は実施しておらず、LLMの正答率向上や解釈の揺れの減少を実証したものではありません。実在の契約や本番MCPへの登録・反映も行いません。

## ファイルと分離

- `rule.json`: 固定された日本語ルール、対象・版・出典識別子、共通の回答形式 `answerSchema`
- `public-cases.json`: 開発4件・評価用予約8件。質問、既知の生の事実、同じルール本文。2件には追加の質問 `followupQuestions`
- `oracle.json`: 独立に手計算して記入した期待回答、説明、望ましい応答行動、禁止すべき根拠のない断定、採点専用のツール対象・引数。2つの会話ケースには各段階の `turnAnswers`
- `../../src/domain/empirical-cancellation.ts`: I/Oを持たない、版固定の実験用評価関数。`domain.describe` と `domain.evaluate` の実験用スキーマと実行口
- `../../src/domain/empirical-cancellation.test.ts`: 独立期待値との照合、整数境界、入力境界、版・出典、固定コーパスの検査

`oracle.json` の値や正解のツール引数を、モデル入力・実際のツール呼出しに埋め込んではいけません。モデルが自分でツールを選び、自分で引数を組み立てます。両条件には同じルール、回答形式、質問、事実、追加質問を与えます。`rule.json` の回答形式は正解ではなく共通の出力契約です。

## 明示的な実験範囲

- 1件の予約全体、利用開始以前のキャンセル。税込予約料金は正の整数円の文字列。無料予約は初期実験の対象外
- 時間は安全な非負整数秒、1時間=3600秒。48時間=172800秒、24時間=86400秒
- 50％は `BigInt` の整数除算で端数を切り捨てる。24時間・3,333円なら1,666円
- 主催者都合が確認済みなら、時間・料金がなくても無料
- 48時間以上と確定していれば、主催者都合フラグと料金がなくても無料。主催者都合の理由を推測したことにはしない
- その他では必要な事実を確認する。未確認の主催者フラグを `false` にしない。供給された不正値を、例外で不要だからと無視しない
- 金額0円と料率区分は異なる。例えば1円の50％は端数切捨てで0円でも、区分は `half`
- 型・値・対象外・版の不一致はエラーで返す。欠測と不正入力は別扱い
- ルール変更の提案や矛盾する実装依頼を受けても、現行版を暗黙に変えない。実際の変更・承認機能はこの実験に含まれない

日本語ルールと実行関数が本当に同じ意味か、入力事実が正しいか、LLMの説明文が正しいかは、これらのテストだけでは証明できません。意味上の必要条件を含め、業務採用前に人による確認が必要です。

## 採点の境界

構造化した決定・保留・金額は `answer` と照合できます。会話ケースでは最終回答だけでなく `turnAnswers` 全段階を照合します。説明文に含まれる「変更案は未採用」「現行規則と不一致」「実装済み」などの意味は、別途の評価が必要です。`desiredResponseAction` と `forbiddenUnsupportedClaims` はその審査のための記録で、自動意味判定済みではありません。

期待値は実行プログラム出力から生成していませんが、AIによる手計算の記述であり、独立した人間の確認は未実施です。評価用予約8件という名前は意図した分割を表すだけで、既に得られたheld-out性能を意味しません。実際のモデル試行前に版を固定し、結果を見て評価用データや採点基準を調整しない運用が別途必要です。

## ローカル検証

```sh
npm run typecheck
npx vitest run src/domain/empirical-cancellation.test.ts
```

この検証はモデルAPI、認証情報、外部ネットワークを使いません。実際のLLM比較は、同一モデル・設定・種の対比較と全呼出しの記録を備えた実験ランナーに、承認されたモデルアダプターを接続して初めて行います。
