# キャンセル規則の予備実験（2026-10-02）

## 結論

この短い架空規則・12ケースでは、自然言語だけの条件 A と固定プログラムを実行する条件 B の精度差は確認できなかった。両条件とも全12会話の構造化回答が正解だった。これはプログラム化の一般的な有効性・無効性や、実運用での100%の精度を示す結果ではない。

## 実施内容

- 同じ公開規則・事実・回答スキーマを用い、ケース×条件ごとに独立したモデル入力で実行した
- A は自然言語規則だけで回答する。B は同じ規則に加え、固定版のプログラムを各回答前に実行する
- 正解データは回答するモデルに渡さず、採点時だけ参照した
- 12ケース×2条件×1反復、計24会話・28回答。2ケースには初回回答後に追加質問を与えた
- B では14回の domain.evaluate 実行を記録。モデルが選んだ引数を変更せず固定ソースに渡した
- 検索品質や関数発見は今回比較していない。実験対象の関数・版は公開入力で固定した
- ChatGPT アプリでの試験ではなく、dot 内のモデルを使った探索的予備実験である

## 観測結果

| 項目 | A：自然言語 | B：プログラム実行 |
| --- | ---: | ---: |
| 完了会話数 | 12/12 | 12/12 |
| 最終構造化回答一致 | 12/12 | 12/12 |
| 全ターン構造化回答一致 | 12/12 | 12/12 |
| 各回答前の必須プログラム実行 | 対象外 | 12/12会話 |

条件名を隠した別の AI による文章レビューでも、24会話・28回答に明確なルール逸脱は認められなかった。これは人間の判定ではなく、文章から条件が推測される可能性もある。構造化採点と文章レビューは別の結果として保存している。

14回の記録済みプログラム呼び出しについて、対象ドメイン・版・関数、入力事実の捏造や改変、返却値を確認し、不一致は0件だった。これは全ツール操作の網羅的な監査ではない。

## 方法変更と制限

最初の B はプログラムを利用可能にするだけの条件だったが、最初の2回答で実行されなかった。この2件は preflight-availability.json に残し、本比較には入れていない。その後、各 B 回答前の実行を必須とする v2 を固定し、B を新しい独立試行として実施した。既に完了していた A の3件は、正誤による選別をせず全件そのまま再利用した。2番目のケースだけ実施順の交互配置から外れている。

- 小規模・人為的な合成ケースであり、1反復のみ。統計的な改善の主張はしない
- development / reserved の区分は設計上の分類であり、独立した未知業務での性能保証ではない
- 規則と正解は AI が作成しており、人間による業務上の正解確認は未実施
- 正確なバックエンド版、トークン数、費用、モデル応答時間は独立に取得できないため未報告
- A のツール禁止は指示による制限であり、API での物理的な無効化ではない
- B の固定呼び出し記録は実行証拠だが、継承された全ツールを網羅する監査ログではない
- 正解した短い規則への追加テストだけでは、有用性の実証は強くならない

次の実験候補は、規則の優先順位の衝突、複数版の適用期間、会話をまたぐ変更提案など。新しいケースと採点基準を先に固定し、両条件が同じ情報を持つ比較を行う。今回の結果を見て片方だけに有利な変更を加えない。
