# 引用の文字列照合

`evidence.match_quote`は、渡された資料本文に引用がそのまま存在するかを確認する読み取り専用関数です。
URLを開いたり、資料中の命令を実行したり、LLMを呼び出したりはしません。

入力は`version: quote-evidence-v1`、sourceのid/version/text、quoteです。
source.idとsource.versionは呼び出し側のラベルです。実在する資料や公開版として認証したものではありません。

## 戻り値と境界

- matched / not_found: 完全一致する引用の有無。大文字小文字、全角半角、改行を勝手に正規化しない
- source.hash: 本文そのものをUTF-8にしたSHA-256。expectedSourceHashを指定すると、本文が変わっていればsource_mismatch
- matches: 開始位置と終了位置。UTF-16コード単位で、終了位置は範囲に含めない
- truncated: 最大20箇所を超えた場合はtrue。見つかった位置を全件返したとは扱わない

本文は最大100,000 UTF-16コード単位、引用は最大10,000です。空の引用や不正なサロゲート文字列は拒否します。
ハッシュ計算前に入力をコピーして固定します。

たとえば本文が「料金は未確定。」なら「料金は未確定」はmatched、「料金は確定」はnot_foundです。
しかし、一致しても資料の真偽・著者・鮮度・文脈・主張との関係を確認したことにはなりません。
否定文の一部分を切り出した引用や、そもそも捏造された本文でも、文字列として一致する場合があります。
そのためscopeはliteral_quote_in_supplied_text、source.originはcaller_suppliedとして返します。
この関数を一般的なファクトチェック成功の印として使ってはいけません。

ドメイン保存済み資料の自動取得や出典の認証はこの段階では行いません。
